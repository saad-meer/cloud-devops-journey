# Day 4 - Linux File Management

## Objective
Practise Linux file management, file comparison and permissions.

## Commands Practised
- touch: Create an empty file.
- echo: Display or write text.
- >: Write output, replacing existing file contents.
- >>: Append output to a file.
- cat: Display file contents.
- cp: Copy files.
- mv: Move or rename files.
- diff: Compare files.
- wc -l: Count lines.
- ls -l: Display detailed file information and permissions.
- chmod: Change file permissions.

## Practical Exercises
1. Created devops-goals.txt.
2. Wrote and appended text to the file.
3. Created devops-goals-backup.txt.
4. Compared the original and backup using diff.
5. Counted the lines using wc -l.
6. Inspected file permissions using ls -l.
7. Changed the backup file permissions to 600.
8. Verified the updated permissions.

## Key Lessons
- The > operator replaces existing file contents.
- The >> operator appends text.
- No output from diff indicates that identical files have no differences to report.
- Permission 600 gives the owner read and write permissions and grants no permissions to the group or others under the standard Unix permission model.
